# Sousa Creative AI

## Como Rodar com o Docker

### 1. Desenvolvimento (com Hot-Reload)
Acesse em: **[http://localhost:3000](http://localhost:3000)**
```bash
docker compose up web-dev --build
```

### 2. Produção (Nginx SPA)
Acesse em: **[http://localhost:3001](http://localhost:3001)**
```bash
docker compose up web-prod --build
```

docker compose up web-dev --build
docker compose up web-prod --build
